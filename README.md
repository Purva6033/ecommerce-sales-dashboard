# Real-Time Sales Dashboard

~ Project Overview
This project is a real-time e-commerce sales monitoring dashboard built using:

- Google Sheets (live data source)
- Google Apps Script (auto data generator)
- Looker Studio (visual analytics)

New sales records are generated every minute, and the dashboard updates automatically.


~ Key Features

✔ Real-time incoming sales  
✔ Dashboard auto-refresh  
✔ Sales trend & KPIs  
✔ Category, city & payment analysis  
✔ 100% beginner friendly  
✔ Perfect for Data Analyst portfolio



~ Tech Stack

| Technology | Purpose |
| Google Sheets | Data storage |
| Apps Script | Auto-generate data every minute |
| Looker Studio | Interactive dashboard |
| JavaScript | Logic for simulation |


~ How It Works

1. Apps Script inserts a new sale every minute  
2. Google Sheets receives the data  
3. Looker Studio connects to the sheet  
4. Dashboard auto-refreshes to show updates


~ Dashboard Metrics

- Total Revenue  
- Total Orders  
- Average Order Value (AOV)  
- Category-wise revenue  
- City-wise performance  
- Payment method breakdown  
- Sales over time


~ Real-Time Logic

The Apps Script runs every 1 minute.
